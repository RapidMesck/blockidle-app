# Pure Rust `wry` + `tao` WebView Stack Directly Navigating to `blockidle.io/play`

`https://blockidle.io/play` sets `X-Frame-Options: DENY` and `Content-Security-Policy: frame-ancestors 'none'`, and relies on same-origin `HttpOnly` session cookies and Server-Sent Events (`/api/eventos`). We chose a pure Rust crate built directly on `tao`, `wry`, and `tray-icon` (rather than a bundled frontend framework or Tauri CLI) that navigates the main WebView directly to `https://blockidle.io/play` and injects client capabilities via `WebViewBuilder::with_initialization_script` and native IPC. This eliminates Node.js/bundler tooling, preserves native same-origin cookie and SSE behavior without a reverse proxy, and gives direct control over window, tray, and script injection lifecycle across Linux and Windows.
